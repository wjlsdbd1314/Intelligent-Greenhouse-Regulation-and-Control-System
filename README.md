# Intelligent Greenhouse Regulation and Control System
> 温室大棚智能调控软件

## 📖 Introduction
This is an agricultural‑oriented web management system for greenhouse planting. It realizes intelligent monitoring and automatic regulation of greenhouse environmental parameters, aiming to improve crop yield and planting quality.

## ✨ Main Features
- Real‑time monitoring of greenhouse environmental data including temperature, humidity and light intensity
- Intelligent control of greenhouse equipment according to collected environmental indicators
- Historical environment data analysis and visualization, providing planting suggestions for growers
- Alarm notification mechanism when environmental abnormalities are detected
- Data dashboard, equipment control records, greenhouse information management

## 📋 Module Description
1. **Home Page**
Display statistical cards and visual charts of each functional module for an overview of greenhouse operation status.

2. **Environment Monitoring**
View analysis charts, environmental data table and greenhouse basic information. Support adding, editing and querying of greenhouse‑related records.

3. **Intelligent Regulation**
Modify system configuration parameters, view large‑screen data visualization, manage environment data and equipment adjustment logs. Record the operating status of ventilation fans, heaters, irrigation systems and other devices.

4. **Historical Data Analysis**
Visualize historical temperature, humidity and illumination data. Perform data statistics and generate targeted planting suggestions based on historical records.

5. **Alarm Notification**
Provide message communication function. Manage alarm records triggered by abnormal temperature, humidity or light. Maintain basic information of each greenhouse.
